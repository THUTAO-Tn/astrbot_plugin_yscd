# 原神兑换码（astrbot_plugin_yscd）

AstrBot 插件：查询**原神国服**兑换码，并在出现**新兑换码时主动推送**给用过 `/yscd` 的会话。

- 指令：`/yscd`
- 数据源：米游社国服官方公告 + 社区聚合接口（BetterGI 同类工具常用）
- 推送：后台定时轮询，发现新码自动发到订阅过的私聊/群聊，**纯文本、不 @ 任何人**

---

## 一、功能

| 能力          | 说明                                                                         |
| ------------- | ---------------------------------------------------------------------------- |
| 查询兑换码    | `/yscd` 输出当前所有有效兑换码                                               |
| 自动订阅      | 发过一次 `/yscd`，该私聊/群聊就默认订阅推送（可在配置中关闭）                |
| 新码推送      | 后台按配置间隔轮询，发现新兑换码主动推送                                     |
| 群聊直接发    | 推送直接发到群里，不 @ 所有人，也不需要群里谁再单独订阅                      |
| 手动订阅/退订 | `/yscd sub`、`/yscd unsub`                                                   |
| 手动刷新      | `/yscd refresh` 立即拉取数据源                                               |
| 过期过滤      | 已知过期日期的兑换码自动从列表隐藏                                           |
| 方便复制      | 兑换码本体单独成行，长按即可复制；可开启 Markdown 代码块适配可点击复制的平台 |

输出格式：

```
🎁 原神国服兑换码 · 共 4 个有效
🕒 更新于 2026-10-24 14:20

【原石×60、冒险家的经验×5】
过期日期：2026-10-25
兑换码：NEEI8A8341OW

【版本前瞻特别节目 #2】
过期日期：2026-10-25
兑换码：NEEIJB764CA3

【摩拉×10000】
过期日期：未知（以官方公告为准，请尽快兑换）
兑换码：MORAHUNTER2026

💡 复制「兑换码：」后面的内容，到 https://ys.mihoyo.com/main/gift 或游戏内兑换
🔔 已订阅新兑换码推送，发送 /yscd unsub 退订
```

新码推送：

```
🎁 原神新兑换码（1 个）

【原石×100、精锻用魔矿×10】
过期日期：2026-10-25
兑换码：NEWCODE99999

发送 /yscd 查看全部兑换码 · 发送 /yscd unsub 退订
```

> 兑换码名称默认取「奖励摘要」；来自米游社公告的码，名称取公告标题（多个码自动编号）。
> 过期日期来自公告里的「有效期」文本；公告没写就如实显示「未知」，不编造日期。

## 二、安装

1. 把 `astrbot_plugin_yscd-v1.0.0` 文件夹整个放到 AstrBot 的 `data/plugins/` 下：

   ```
   AstrBot/data/plugins/astrbot_plugin_yscd-v1.0.0/
   ├── main.py
   ├── metadata.yaml
   ├── _conf_schema.json
   ├── requirements.txt
   └── README.md
   ```

2. 在 WebUI「插件」页刷新/重载，或重启 AstrBot。
3. 依赖 `httpx`（AstrBot 本体自带）；若提示缺少模块：
   ```bash
   pip install -r requirements.txt
   ```

> `metadata.yaml` 里的 `repo` 是占位地址，发布到 GitHub / 插件市场前记得改成你自己的仓库地址。

## 四、配置项（WebUI → 插件 → 原神兑换码 → 配置）

| 配置                     | 默认 | 说明                                                 |
| ------------------------ | ---- | ---------------------------------------------------- |
| `enable_miyoushe_source` | 开   | 启用米游社官方公告源（国内网络推荐）                 |
| `enable_ennead_source`   | 开   | 启用社区聚合源（补全兑换码/奖励，兜底）              |
| `enable_auto_push`       | 开   | 是否后台轮询并推送                                   |
| `auto_subscribe`         | 开   | 发过 `/yscd` 是否自动订阅                            |
| `fetch_interval_minutes` | 30   | 轮询间隔（分钟，最小 5）                             |
| `cache_ttl_minutes`      | 10   | 查询缓存时间（分钟）                                 |
| `max_codes_display`      | 12   | 单次最多展示个数                                     |
| `max_push_codes`         | 5    | 单次推送最多包含的新码个数                           |
| `use_code_block`         | 关   | 兑换码用 Markdown 代码块包裹（可点击复制的平台可开） |
| `http_timeout`           | 15   | 请求超时（秒）                                       |
| `proxy`                  | 空   | HTTP 代理，如 `http://127.0.0.1:7890`                |

## 五、实现说明

### 数据源

1. **米游社国服官方公告**（`api-takumi.miyoushe.com`）
   - `getNewsList` 拉国服公告列表 → 筛出标题含「兑换码 / 前瞻 / 直播 / 礼包」的公告（最多 3 篇）→ `getPostFull` 取正文
   - 正文去 HTML 标签后，只在「兑换码」关键词后 400 字内匹配候选码，降低误判
   - 同时解析「有效期至 2026/01/01」这类文本，得到**准确的过期日期**
2. **社区聚合接口**（`api.ennead.cc/mihoyo/genshin/codes`）
   - 返回 `active` / `inactive`，用 `active` 补全兑换码与奖励
   - 奖励名做中英对照：Primogem→原石、Mora→摩拉、Hero's Wit→大英雄的经验、Mystic Enhancement Ore→精锻用魔矿……

两个源按兑换码合并去重，米游社的有效期优先；**任意一个源挂掉都不影响另一个**，
两个都挂时自动回退到本地缓存，不会报错给用户。

### 订阅与推送

- 订阅键是 AstrBot 的 `unified_msg_origin`（会话唯一 ID），持久化在
  `data/plugin_data/astrbot_plugin_yscd/state.json`。
- 后台任务在 `initialize()` 启动、`terminate()` 取消，热重载不会残留任务。
- **首次加载只入库不推送**（历史兑换码不会刷屏）；之后每次多出来的码才推送。
- 推送只用纯文本，链里没有 `At` / `AtAll`，所以群里不会出现 @所有人；
  群里只要触发过一次 `/yscd`，之后的推送就直接发到这个群，不需要其它人再订阅。
- 推送失败累计 3 次的会话会被自动移除；每条码记录 `pushed` 标记，不会重复推送。
- 单次发现的新码超过 `max_push_codes` 时只推前几个，其余提示 `/yscd` 查看。

### 关于「一键复制按钮」

AstrBot 目前的消息组件里没有「复制到剪贴板」类型的按钮（QQ 机器人按钮只支持
跳转链接 / 发送指令 / 回调 / 输入，没有复制动作），因此按需求**放弃按钮**，改用：

- `兑换码：XXXX` 后面不跟任何多余字符，长按即可复制；
- 需要「点击复制」时打开 `use_code_block`，在支持 Markdown 的平台
  （QQ 官方机器人 Markdown 消息、Telegram、Discord、Slack 等）会渲染成代码块，点击即复制。

## 六、注意事项

- 只处理**国服**（米游社国服接口），不含国际服兑换码。
- 兑换码时效很短（前瞻直播码通常 24~48 小时失效），收到推送请尽快兑换。
- 米游社公告偶尔把兑换码放在图片里，这种情况解析不到，只能靠聚合源补全；
  公告没写有效期时显示「未知」，不会猜日期。
- 第三方公开接口若被官方调整可能失效，更新解析逻辑即可；插件已做异常降级，不会因此崩溃。
- 数据只保存在 `data/plugin_data/astrbot_plugin_yscd/`，重装插件不会丢；
  需要彻底重置时删掉该目录。

---

## 七、排错

- 查不到码：先看 AstrBot 日志里有没有 `[astrbot_plugin_yscd] ... 拉取失败`，
  多半是网络/接口波动；可在配置里关掉其中一个源单独试。
- 想重置订阅和缓存：停用插件后删掉 `data/plugin_data/astrbot_plugin_yscd/`。
- 想调快/调慢推送：改 `fetch_interval_minutes` 后重载插件即可生效。
