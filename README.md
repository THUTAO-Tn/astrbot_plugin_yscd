# 原神兑换码（astrbot_plugin_yscd）

AstrBot 插件：查询**原神国服**兑换码，出现新兑换码时主动推送给用过 `/yscd` 的会话。

> 国服兑换码现在很多是**中文短语**（7.2 前瞻是「千星奇域一起拍拍拍 / 坏灭肇始之时 / 天才少年米提亚登场」），
> 国际服的英文码（`hourofruin` / `expertmitya` / `phototime`）**国服不可用**。
> 本插件只采用米游社国服官方公告，不再混入国际服/第三方聚合码。

- 指令：`/yscd`
- 数据源：米游社国服官方公告 + 前瞻直播资讯
- 推送：后台定时轮询，发现新码自动发到订阅过的私聊/群聊，**纯文本、不 @ 任何人**

- 一组公告一块：`【组名】` → `有效期至：` → （有奖励才显示）`奖励：` → `兑换码：`（单条）或 `兑换码 1/2/3：`（多条）

- 新码推送同样排版，首行换成 `原神兑换码（新）`，不含缓存时间

## 二、安装

把 `astrbot_plugin_yscd-v1.0.0` 整个文件夹放到 `AstrBot/data/plugins/`，然后在 WebUI「插件」页刷新/重载。

```
AstrBot/data/plugins/astrbot_plugin_yscd-v1.0.0/
├── main.py
├── metadata.yaml
├── _conf_schema.json
├── requirements.txt
└── README.md
```

依赖 `httpx`（AstrBot 自带）。`metadata.yaml` 里的 `repo` 是占位地址，发布前改成你自己的仓库。

## 四、配置

| 配置 | 默认 | 说明 |
| --- | --- | --- |
| `enable_miyoushe_source` | 开 | 米游社国服公告数据源 |
| `enable_auto_push` | 开 | 后台轮询 + 新码推送 |
| `auto_subscribe` | 开 | 发过 `/yscd` 就自动订阅（群聊直接发群里，不 @ 所有人） |
| `foreshadow_reward_template` | 开 | 前瞻直播奖励用固定模板（100原石+矿 / +经验书 / +摩拉） |
| `manual_codes` | 空 | 手动补录，每行 `标题\|有效期\|兑换码\|奖励` |
| `scan_posts_per_round` | 6 | 每轮最多抓几篇公告详情 |
| `fetch_interval_minutes` | 30 | 轮询间隔 |
| `cache_ttl_minutes` | 10 | 查询缓存时间 |
| `max_push_codes` | 6 | 单次推送最多几条 |
| `http_timeout` | 15 | 请求超时（秒） |
| `proxy` | 空 | HTTP 代理，如 `http://127.0.0.1:7890` |

`manual_codes` 示例（公告解析不到时兜底）：

## 五、实现说明

### 抓取链路

1. `getNewsList`（gids=2，type=1/2/3）拉国服公告列表，标题含「兑换码/前瞻/直播/礼包/活动」的优先，其余用最近公告补位；
2. `getPostFull` 取正文。若返回 403（米游社风控），自动带 `DS` 签名（web 端 salt）重试一次；
3. 正文去 HTML 标签后提取：
   - **兑换码**：支持 `兑换码：XXX`、`兑换码1：XXX`、`兑换码：` 后换行列表、`XXX、YYY` 一行多码，以及中文短语码；
   - **有效期**：`有效期至 2026/10/26`、`2026年10月26日` 等写法；
   - **奖励**：`奖励：…；…` 行，没有则用前瞻模板补；
4. 按兑换码去重入库，新码推送。

### 去误判

- 候选码限制 2~24 字、不含标点空格，且不能包含「兑换/领取/如下/点击/前往/有效期/奖励/活动」等正文词；
- 纯英文数字的旧式码要求 ≥6 位且含字母；
- 只解析「兑换码」关键词后面 400 字内的内容。

### 订阅与推送

- 订阅键是 `unified_msg_origin`，存在 `data/plugin_data/astrbot_plugin_yscd/state.json`；
- 首次加载只入库不推送（不会刷历史码），之后新增的才推；
- 推送纯文本，无 `At`/`AtAll`；群聊触发过一次 `/yscd` 后就一直推这个群；
- 连续失败 3 次的会话自动移除订阅；
- 过期超过 30 天的记录会自动清理。

## 六、排错

| 现象 | 检查 |
| --- | --- |
| 查不到码 | 日志里 `[astrbot_plugin_yscd] ... 风控拒绝（401/403）` → 服务器 IP 被米游社风控，配 `proxy` 或换网络 |
| 只显示部分码 | 调大 `scan_posts_per_round` |
| 码不对/想手工补 | 用 `manual_codes` 填，优先级同公告 |
| 想重置 | 停用插件后删 `data/plugin_data/astrbot_plugin_yscd/` |

- 只处理国服，插件不请求任何国际服接口；
- 米游社公告若把兑换码放在图片里，文本解析不到，用 `manual_codes` 补。
